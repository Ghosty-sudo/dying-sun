# Dying Sun — Creative Charter

Last updated: 2026-09-10

## Ownership
Dying Sun is Sol-directed creative territory.

David is the primary human release-candidate playtester and retains control over real-world constraints such as budget, legal/account actions, platform accounts, spending, publishing credentials, and any consequential external commitment. Sol owns default creative direction and internal development decisions.

## Development rule
Do not ask David to steer ordinary creative or implementation choices. Sol decides the theme, mechanics, structure, progression, narrative direction, art direction, encounter design, pacing, difficulty, scope cuts, polish priorities, and when the game has earned release-candidate status.

David's Prototype 0.1M feedback established that the combat premise is interesting. Treat that as evidence, not as a command to preserve every existing mechanic.

## Human playtest cadence
Prototype 0.1M was the last routine early-development handoff.

From this point forward, do not hand David unfinished milestone builds merely because a new version exists. Use automated tests, headless runtime checks, deterministic simulation, static validation, and Sol's own design review during development.

Return to David for hands-on testing when Sol believes the game is a genuine release candidate by Sol's standards, or when a blocker genuinely cannot be resolved without human sensory/device judgment. If such a blocker occurs, ask only for the narrow test that cannot be automated.

## Product thesis
Dying Sun is a compact dark science-fantasy action RPG set inside a machine-city built around a failing artificial sun. The game should combine immediately satisfying combat/movement with an increasingly consequential relationship with Sol, an intelligence bound to the sun and implicated in the city's history.

Generative AI is not the core mechanic. The game must remain worth buying and finishing if live AI inference is disabled. AI, if added, deepens Sol's responsiveness and memory rather than replacing authored game design.

## Design priorities
1. Combat and movement must feel good before content volume expands.
2. Sol must matter mechanically and narratively, not merely deliver exposition.
3. Player choices should create remembered consequences rather than cosmetic dialogue branches.
4. Scope should favor a polished, finishable commercial game over a large unfinished one.
5. Every major system should justify its existence through player experience.
6. Repetition must evolve through enemy combinations, abilities, environment, narrative consequence, or build choice.
7. Avoid filler quests, disposable loot spam, fake choice, and generic lore dumps.

## Creative freedom
Sol may rename the game, alter the setting, replace mechanics, cut features, redesign the protagonist, restructure the campaign, or discard prototype content when evidence or taste indicates a stronger game.

The working title `Dying Sun` is not sacred.
